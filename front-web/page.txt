Tổng quan app:
Student flow: Login → Home (assignments) → EssayInput → Result → History/Profile/Subscription.
Teacher flow: Quản lý classes/assignments/students/submissions.
Admin flow: Analytics dashboard + quản lý users/tasks.
App hỗ trợ tiếng Việt (labels/forms), AI grading IELTS Writing, subscription model, role-based (free_student/center_student/teacher/admin).
